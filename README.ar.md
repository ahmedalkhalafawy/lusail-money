# lusail-money

مكتبة صغيرة لعرض المبالغ والعملات داخل النص العربي والنصوص المختلطة الاتجاه.
استُخرج ملف الأدوات من كود لوسيل دون نسخ التطبيق أو إعدادات قاعدة البيانات.

## المشكلة التي تعالجها

قد يتغير موضع العملة والرقم داخل الفقرة العربية. تعزل المكتبة المبلغ والعملـة
معًا باستخدام محارف Unicode المخصصة لاتجاه النص. كما تتضمن أدوات العرض الأصلية
للتعامل مع الصفر السالب والقيم العددية غير المنتهية.

## التشغيل

يلزم Node.js إصدار 22.18 أو أحدث للبناء، ولا توجد حزم خارجية مطلوبة:

```sh
node scripts/build.mjs
node --test tests/*.test.mjs
```

## مثال

```js
import { moneyText } from 'lusail-money';
const line = `الإجمالي: ${moneyText('171.00', 'ج.م')}`;
```

ابنِ المكتبة أولًا وثبتها من مسارها المحلي كما يوضح README الإنجليزي.
الكود متاح على https://github.com/ahmedalkhalafawy/lusail-money، ولم تُنشر الحزمة
على npm بعد، واسمها غير محجوز هناك.

## حدود مهمة

- هذه أدوات عرض وليست نظام محاسبة أو احتساب ضرائب أو تحقق من المدفوعات.
- حد تحويل القيم الصغيرة إلى صفر ثابت عند 0.005 وموروث من التطبيق الأصلي؛
  لذلك لا يناسب وحده القيم التي تحتاج دقة أدق من منزلتين عشريتين.
- التقريب يستخدم سلوك JavaScript الأصلي، ولا يقدم حسابًا عشريًا ماليًا دقيقًا.
- التنسيق لا يحمي من HTML الضار أو محارف اتجاه النص القادمة من مدخلات غير موثوقة.
- الاختبارات تتحقق من النص والسلوك العددي؛ الطباعة الحرارية والعرض الفعلي يحتاجان
  تجربة على الأجهزة المستهدفة.
