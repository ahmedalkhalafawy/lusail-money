# Security

This package performs local string formatting and numeric display normalization.
It contains no network calls, authentication, database access, or telemetry.

It is not an input validator, HTML sanitizer, protection against bidi spoofing,
or authorization boundary. Use trusted currency labels and validated amounts.
Never use display normalization as the canonical value for financial records.

Do not include credentials or real customer data in bug reports. Before this
repository is made public, the owner should configure a private vulnerability
reporting channel. No monitored public reporting address is claimed here.
